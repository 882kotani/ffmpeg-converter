# メディア変換（FFmpeg Web アプリ）

ブラウザに動画・音声をドラッグ＆ドロップして、形式変換・音量調整・結合・プレビュー切り出し・回転などを行う洗練された高機能メディア処理ツールです。
変換処理はサーバー側のインメモリキューで順次安全に処理され、完了すると自動でダウンロードされます。

## 機能一覧

| 機能                 | 内容                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------- |
| 形式変換             | MP4 / MOV（H.264+AAC）、MXF（mpeg2video+pcm_s16le）、MP3（libmp3lame）、WAV（pcm_s16le）                      |
| 音量調整             | `volume=±NdB`。映像は `-c:v copy` で高速保持                                                                  |
| ビットレート変更     | 入力動画の現在ビットレートを表示。映像 `-b:v` / 音声 `-b:a`（例: `1000k`, `320k`）                            |
| フレームレート変更   | 入力動画の現在FPSを表示。`fps=N` フィルタ                                                                     |
| リサイズ             | 入力動画の現在解像度を表示。横 1920 / 1280 / 720 以内（縦横比維持・偶数ピクセル強制）                         |
| 回転                 | 動画を時計回りに 90度 / 180度 / 270度 回転（リアルタイムプレビュー対応、偶数ピクセル制約維持）                |
| 動画結合             | 直感的なドラッグ＆ドロップ並び替えに対応。表示順に連結し、1本の MP4 に統一                                    |
| 静止画＋音声 → MP4   | 音声の長さに合わせ `-t` で余分な末尾（+4秒超過）を切り取り、ぴったり一致した MP4 を生成（順不同ドロップ対応） |
| 動画・音声の切り出し | プレビュー再生しながら「START」「STOP」で範囲指定。複数範囲の追加・削除・自動結合に対応（再エンコード）       |

## 主な特徴・UX/UIハイライト

- **技術諸元・FFmpegコマンド確認モーダル（「i」ボタン）**:
  - 各ツールのメニューボタンおよびパネル見出し横に情報アイコン（`i`）を設置。
  - タップすると「何が変更され、何が無劣化で保持されるか」「実行されるFFmpegコマンドライン例」「コーデックやカラー空間（VUIタグ）の詳細」を確認できます。
- **堅牢な静止画＋音声処理**:
  - 静止画と音声のドロップ順序に依存しない安全設計。静止画単体の無駄なプローブ解析をスキップし、通信例外を防止。
  - `-map 0:v:0 -map 1:a:0` による正確なストリームバインドと、出力側 `-t` 指定による尺ピッタリの動画出力。
- **動画の回転とリアルタイムプレビュー**:
  - ドロップした動画を 90度・180度・270度（時計回り）に回転。
  - 選択した角度がプレビュー画面でリアルタイムに回転反映され、向きを確認しながら変換可能。
- **色味保持・ガンマシフト防止（MOV → MP4 等）**:
  - 入力ファイルのカラーメタデータ（`color_primaries`, `color_trc`, `colorspace`, `color_range`）を自動解析。
  - エンコード時に H.264 VUI タグを正しく引き継ぎ・付与することで、QuickTime Player やブラウザでの色あせ・白飛び・ガンマのズレを防止します。
- **入力メディア情報のリアルタイム表示**:
  - ファイル選択時、バックエンド（`ffprobe`）で即時にメタデータを解析。
  - 現在のビットレート、フレームレート、画面サイズ（解像度）が整理されたチップバッジとして表示されます。
- **直感的なファイル並び替え**:
  - 結合リストのアイテムをマウスでドラッグ＆ドロップ、または矢印ボタンでスムーズに並び替えできます。
- **リッチなリアルタイム進捗・残り時間表示**:
  - FFmpeg のエンコード進捗をリアルタイムにトラッキング。
  - 処理率（%）、残り推定時間（ETA）、エンコード速度をグラフィカルなプログレスバーとともに表示します。
- **排他制御・自動クリーンアップ**:
  - 最大同時実行数の制限（インメモリキュー）。
  - アップロード元および変換後ファイルはダウンロード完了時やエラー・キャンセル時に完全自動削除。

## 前提環境

Node.js 18 以上、および **FFmpeg / ffprobe が PATH に通っていること**。

```bash
# macOS (Homebrew)
brew install ffmpeg

# Ubuntu / Debian
sudo apt update && sudo apt install -y ffmpeg

# Windows (winget)
winget install Gyan.FFmpeg
```
